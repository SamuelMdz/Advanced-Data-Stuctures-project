# Advanced-Data-Stuctures-project
RapidResponse is a first responder coordination system designed to model the distribution and dispatch of emergency response units based on incident severity and type. The system simulates emergency incidents occurring within the Houston area and determines which response agencies—such as the Fire Department, Police Department, or Emergency Medical Services (EMS)—are required. Based on predefined assumptions and system constraints, RapidResponse identifies the appropriate number and type of responders, selects the closest available units, and estimates their arrival times. This project focuses on the modeling of emergency response operations rather than real-time deployment.
